# CSS Gradient Generator

A fast, lightweight, and modern tool to create beautiful CSS gradients with live preview, multi-format export, and zero build dependencies.

🚀 **Live Demo**: [turborx.github.io/CSS-Gradient-Generator](https://turborx.github.io/CSS-Gradient-Generator/)

---

## ✨ Key Features

- ⚡ **Live Gradient Preview**: Real-time rendering for Linear, Radial, Conic & Repeating gradients.
- 🎨 **Color Stop Management**: Multi-stop custom positioning, alpha transparency, and instant **Reverse Colors**.
- 🛠️ **Multi-Format Export**: One-click copy & download for **CSS**, **Tailwind CSS**, **SCSS**, **JSON**, and **SVG**.
- 🌓 **Appearance Modes**: Integrated **Light**, **Dark**, and **System** theme switching.
- 📱 **Fully Responsive**: Mobile-friendly glassmorphism UI with responsive hamburger drawer navigation.
- ⌨️ **Power Shortcuts**: `Ctrl/Cmd + C` (Copy), `Ctrl/Cmd + Z / Y` (Undo/Redo), `Ctrl/Cmd + R` (Random Design).

---

## 🚀 Quick Start

No build step required. Clone the repo and open `index.html` directly or serve locally:

```bash
git clone https://github.com/TurboRx/CSS-Gradient-Generator.git
cd CSS-Gradient-Generator
npx serve .
```
