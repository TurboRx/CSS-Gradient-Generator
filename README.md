## Introduction

Welcome to the CSS Gradient Generator! This tool allows you to create beautiful CSS gradients with a live preview and the ability to copy the generated CSS code. It's designed to be user-friendly and versatile, making it easy for developers and designers to create stunning gradients for their projects.

## Features

- Live preview of gradients
- Support for multiple gradient types (linear, radial, conic, and repeating variants)
- Easy-to-use controls for customizing gradients
- Add and remove color stops dynamically
- Toggle between light and dark modes
- Generate random gradient designs
- Copy generated CSS code to clipboard
