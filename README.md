## Introduction

Welcome to the CSS Gradient Generator! This web-based tool helps developers and designers easily craft stunning CSS gradients. Whether you're building a UI, prototyping a landing page, or exploring color ideas, this generator gives you live previews and customizable options with zero hassle.

---

## Features

- Live gradient preview  
- Supports linear, radial, conic, and repeating gradients  
- Drag & drop color stops dynamically  
- Dark and light theme toggle  
- Random gradient generator  
- Copy-to-clipboard functionality for clean CSS code
